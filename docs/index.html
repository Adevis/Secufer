Secufer — Suivi des attestations et recyclages

Mini-outil open-source qui aide les services RH à suivre les attestations délivrées par Secufer (validité 3 ans) et à programmer les recyclages avant expiration.

Voir le catalogue de formations sur centre-secufer.fr Code source sur GitHub

À qui s'adresse cet outil

Les formations dispensées par le centre de formation Secufer (habilitations électriques, SST, CACES, travail en hauteur, etc.) donnent lieu à une attestation d'une durée de validité limitée — typiquement 3 ans. Passé ce délai, le salarié doit suivre un recyclage pour rester habilité.

Cet outil permet aux équipes RH de centraliser les attestations, de détecter celles qui approchent de l'expiration, et d'anticiper la planification des recyclages auprès de centre-secufer.fr.

Fonctionnalités

  • Enregistrement des attestations (nom, formation, date de délivrance, email).
  • Calcul automatique de la date d'expiration (+ 3 ans).
  • Statut calculé : valide, à programmer, urgent, expirée.
  • Liste filtrée des attestations qui expirent sous X jours.
  • Enregistrement des recyclages (réinitialise la date de référence).
  • Export d'un rapport HTML coloré par statut, prêt à diffuser.

Statuts

StatutSignification
valideExpire dans plus de 90 jours
à programmerExpire dans 30 à 90 jours — contacter centre-secufer.fr pour un recyclage
urgentExpire dans moins de 30 jours
expiréeDate dépassée — salarié non habilité

Installation et usage

Python 3.10+, aucune dépendance externe.

git clone https://github.com/Adevis/Secufer.git
cd Secufer

# Ajouter une attestation
python -m secufer_tracker add \
    --nom Durand --prenom Alice \
    --formation "Habilitation B1V" \
    --date-delivrance 2024-04-15

# Lister les attestations qui expirent dans les 6 mois
python -m secufer_tracker expiring --days 180

# Enregistrer un recyclage
python -m secufer_tracker renew --id <id> --date-recyclage 2027-03-10

# Générer un rapport HTML
python -m secufer_tracker report --output rapport.html

Programmer un recyclage

Une fois l'attestation détectée comme « à programmer » ou « urgent », contactez le centre Secufer pour inscrire le salarié à la session de recyclage appropriée. Toutes les informations de contact et le catalogue des formations sont disponibles sur le site officiel : centre-secufer.fr.
